===Independent Release ForcePacks===
Several ForcePacks were released directly through retail following the first [[2019 Clan Invasion Crowdfunding Campaign]].  Many of these had a Mercenaries theme which would mesh with the [[BattleTech Beginner Box, Second Edition]] and the [[2023 Mercenaries Crowdfunding Campaign]].  Note the [[BattleTech: Somerset Strikers ForcePack|Somerset Strikers ForcePack]] was released in the Mercenaries Crowdfunding Campaign and thus included in that section.

Table Notes: The column denoted "Parts" gives the number of parts per box set for each miniature prior to assembly. The column denoted "Catalog Number" can show different product codes if the miniature was available in different boxes.
