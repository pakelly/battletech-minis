===Premium Miniatures===
Catalyst Game Labs offers multiple online only miniatures that can be ordered from the webstore. These are shipped unassembled, with multiple possible configurations. Additionally the ERIS kit includes a hammerhead torso. 

Table Notes: Name is as listed on packaging. The column denoted "Parts" gives the number of parts per box set for each miniature prior to assembly (the hex base is not included in these numbers). CGL is the license holder not the manufacturer.
